# 📧 AI Spam Detector

A simple AI project that detects SPAM messages using Machine Learning.

## 🚀 How to run
pip install -r requirements.txt
streamlit run app.py

## 🧠 Tech Used
- Python
- Scikit-learn (Naive Bayes)
- TF-IDF Vectorizer
- Streamlit for website

## ✨ Features
- Detects spam messages like "Free money"
- Detects safe messages like "Hi how are you"
- Simple web interface
